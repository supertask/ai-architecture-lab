# 屋根を突き抜けた間仕切り壁を直す

Archicad のプロジェクト「house_from_scratch」で、2階の間仕切り壁のうち1枚が屋根の上に突き出ています（上端 GL+9.95、屋根の上端は GL+7.5）。図面の最高高さがこの壁で 9,950 になってしまっています。

- Archicad への命令は Tapir を使う（<KIT>/tapir_http.py の call(port, command, params)、port は 19723）。スクリプトは <KIT>/ に書いて実行する。
1. 壁の上端が屋根（スラブ）の上端より上にある壁をすべて探し、間仕切りなら2階の天井（その上のスラブの下端）までの高さに直す。外壁は変えない。直した壁の数と、前後の上端の高さを書く。
2. 次のビューの 2D 要素（線・ポリライン・塗り・文字・寸法・円・円弧）をすべて消す。図面を描き直すため。
   - 断面ウインドウ「S-01 S北」「S-01 S東」「S-01 S西」「S-01 B-B」
   - 平面図「2. 2FL」（storyIndex 1）の 2D（2階に置かれたものだけ。1階の 2D は消さない）
3. 最後に SaveProject を送る。
- 使ってよいのは、この指示と Archicad から読める情報だけ。スキル、記憶、過去の会話、session_search、honcho、delegate は使わない。
- 終わったら「完了」と、したことを3行以内で書く。
