# 立面図を、実務の作図ルールで仕上げる

Archicad で、断面ウインドウ「S-01 S東」（東立面図）を、最初に ChangeWindow で開いてください。注記と塗りはまだ何もありません。
この立面図を、実務の作図ルール（<KIT>/作図ルール_立面.md）に合わせて仕上げてください。

- Archicad への命令は Tapir を使う（<KIT>/tapir_http.py の call(port, command, params)、port は 19723）。スクリプトは <KIT>/ に書いて実行する。
- 足すもの：壁とガラスの塗り、GL とレベル、高さの寸法、通り芯の記号、横の寸法、図名。数値はモデル（壁・スラブ・窓）から読む。
- 高さの基準：GL＝敷地の上面（モデルの z=0）、1FL＝GL+100（モデルの z=0.1。ストーリー 1FL のレベル）。高さは全部 GL 基準で書き、1FL と GL は別の線にする。値はモデルから読む（前に描いた図の値は使わない）。
- GetElementsInDrawOrder は使わない（前回これの後に Archicad が落ちた）。重い読み取りは1回ずつ分けて送る。
- 通り芯は <KIT>/grid.json の1組だけを使う（自分で新しく決めない）。図面に出る通り芯の名前と位置を、ほかの図面とそろえるため。
- 横の寸法は、通り芯の外側（外壁の端まで）の寸法も入れ、合計を全長にそろえる。
- 種類ごとに分けて Archicad に送る（全部を1回で送らない）。送る前に、何を描くかを日本語1行で書く。
- 使ってよいのは上のルールファイル、<KIT>/grid.json と、Archicad から読める情報だけ。スキル、ほかのファイル、記憶、過去の会話、session_search、honcho、delegate は使わない。
- 壁・窓・スラブなどのモデルは変えない。2D の注記と塗りだけを足す。
- 終わったら「完了」と、描いたものを3行以内で書く。
