# 1階平面図を直す（4回目・最後）

Archicad のプロジェクト「house_from_scratch」で作業します。最初に平面図を ChangeWindow（windowType FloorPlan, storyIndex 0）で開いてください。前回までに AI がこの図に注記を描き、直してきました。最後の点検で残った問題を、下のとおり直してください。

- Archicad への命令は Tapir を使う（<KIT>/tapir_http.py の call(port, command, params)、port は 19723）。スクリプトは <KIT>/ に書いて実行する。
- 作図ルール：<KIT>/作図ルール_平面.md（迷ったらこれに従う）。通り芯は <KIT>/grid.json。
- 高さの基準：GL＝モデルの z=0、1FL＝GL+100。値はモデルから読む。
- 既にある 2D 要素は、直す物だけを動かす・消す・描き直す。正しい物は残す。済んでいる項目は確かめるだけで飛ばす。
- GetElementsInDrawOrder は使わない（Archicad が落ちたことがある）。重い読み取りは1回ずつ分けて送る。
- 送る前に、何を直すかを日本語1行で書く。直したら、その場所の要素の座標を読み直して、重なり・接触が無くなったことを数値で確かめる（文字・円と線のすき間は紙の上で 1mm 以上）。
- 使ってよいのは、この指示、ルールファイル、grid.json と Archicad から読める情報だけ。スキル、ほかのファイル、記憶、過去の会話、session_search、honcho、delegate は使わない。
- 壁・窓・スラブなどのモデルは変えない。モデルが原因で 2D では直せない物は、直さずに「モデル側：…」と報告に書く。
- 直した所の近くに、新しい重なりを作らない（直した後、半径 1m の中の文字・線を読み直す）。
- 終わったら「完了」と、直したものを箇条書き6行以内で書く。

## 直すこと（重要な順）
1. 車庫の外周で壁が二重に見え、間に白い帯がある。内側の線が AI の描いた 2D の線・塗りなら消す。モデルの壁なら直さず報告する。
2. 車庫の上（X5／Y4 付近）と下（Y1）に、扉の開きの円弧の切れ端のような線がある。AI の描いた 2D なら消す。
3. 車庫の面積の行が X5 の通り芯に近い。文字の塊を車庫の右側へ移し、X5 から 0.3m 以上離す。WD1-1・「WIC」が Y3 に近いので、上へ 0.15m 移す。
4. 面積と帖が無い部屋（ホール、WC、浴室、サウナ、収納、WIC など、ゾーンのある部屋）にも、ほかの部屋と同じ書式（室名 3mm／面積・帖 2.5mm）で入れる。値はゾーンの面積から読む（1帖=1.62㎡、小数2桁）。入らない狭い部屋は、室名の外に引出線で出す。
5. GL の説明文を「GL＝敷地面（GL±0）」に統一する（全角の＝、スペースなし）。
