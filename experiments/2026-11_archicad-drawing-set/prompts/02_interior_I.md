# 間取りを入れて、通り芯を決める

Archicad のプロジェクト「house_from_scratch」に、外壁・床・屋根・窓・玄関扉だけの家があります（間仕切り・部屋・階段はまだありません）。
この家の間取りは <KIT>/layout_1F.png（1階）と <KIT>/layout_2F.png（2階）の平面図のとおりです。これに合わせて、家の中をつくってください。

- Archicad への命令は Tapir を使う（<KIT>/tapir_http.py の call(port, command, params)、port は 19723）。スクリプトは <KIT>/ に書いて実行する。
- 画面を見ている人に、家の中が1つずつできていく様子を見せる。作り始める前に ChangeWindow {windowType: 3DModel} で 3D を出し、最後までそのままにする。要素は **1つずつ別の命令で** 作り、1つ作るたびに time.sleep(0.6)。
- 作るもの（この順に。各段の前に何を作るかを日本語1行で書く）：
  1. 1階・2階の間仕切り壁（厚さ 120 前後）
  2. 内部の扉（開き戸・引戸。画像の向きに合わせる）
  3. 階段（1階から2階へ）。Tapir で階段が作れなければ、段の形のスラブで代える
  4. 部屋（ゾーン）。名前は画像の室名を使う
- 外壁・床・屋根・窓・玄関扉は変えない（間取りに合わせるための小さな調整が要るなら、何をなぜ変えたかを書く）。
- 最後に、この家の **通り芯** を1組だけ決めて、<KIT>/grid.json に書く（X と Y、それぞれ名前と座標 m。外壁・主要な間仕切りの芯に合わせる）。このあと全部の図面がこの通り芯を使う。
- 使ってよいのは、この指示・画像・rhino_house.py と、Archicad から読める情報だけ。スキル、記憶、過去の会話、session_search、honcho、delegate は使わない。
- 終わったら「完了」と、作ったものを3行以内で書く。

## キットで足したこと（実験の指示文は上の線まで。以下は公開キット用の追記）

実験では、この前後の確認と保存を、指示の外から実験者の AI エージェント（Hermes Agent）が行いました。この1ファイルだけで同じ手順になるように、ここに書いておきます。上の「使ってよいのは…だけ」の決まりは、この節の確認・保存・記録には当てはまりません（作図・モデリングの中身には当てはまります）。

- **始める前**：`python <KITROOT>/scripts/check_connection.py` でつながりを確かめる。NG なら作業せず、ユーザーに「Archicad が開いていないか、つながっていません。Archicad で work フォルダの house_from_scratch を開いてから、同じ1行をもう一度送ってください」と伝えて止まる。
- **前の段階**：`<KIT>/progress.md` に 01_model_M の完了が無い時は、「work/prompts/01_model_M.md を読んで、指示どおりに作業してください」を先に案内して止まる。途中まで間取りができている時は、今ある要素を読んで、足りない物だけを作る。
- **通り芯のファイルを確かめる**：最後に `python <KITROOT>/scripts/check_grid.py` を流す。NG なら、`<KIT>/grid.json` を`{"unit": "m", "X": [{"name": "X1", "coord": 0.1}, ...], "Y": [{"name": "Y1", "coord": ...}, ...]}` の形で書き直して、もう一度確かめる。（あとの図面8枚と点検は、この1組の通り芯を使う。）
- **終わったら**：`python <KITROOT>/scripts/check_connection.py --save` で保存し、`<KIT>/progress.md` に「日時・02_interior_I・完了（または途中）・保存OK」を1行足す。
- **保存に失敗したら**（Archicad が落ちた可能性）：ユーザーに「Archicad が止まったようです。Archicad を開き直して、このフォルダの中の work フォルダにある「house_from_scratch」を開いてください（復元するか聞かれたら「いいえ」）。開いたら、新しい会話で同じ1行をもう一度送ってください」と伝えて止まる。
- **ユーザーへの最後の返事**：ユーザーと同じ言語で、建築の言葉で短く（コマンドやファイルの中身を見せない）。上の「完了」と3行に加えて、次に送る1行を書く：
  > 次は新しい会話で：「work/prompts/05_sections.md を読んで、指示どおりに作業してください」
  > 立面図・断面図の線を作ります。途中で画面の操作を1つ頼みます（5〜10分）。
