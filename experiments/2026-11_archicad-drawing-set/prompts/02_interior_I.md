# 間取りを入れて、通り芯を決める

Archicad 26 のプロジェクト「house_from_scratch」に、外壁・床・屋根・窓・玄関扉だけの家があります（間仕切り・部屋・階段はまだありません）。
この家の間取りは <KIT>/layout_1F.png（1階）と <KIT>/layout_2F.png（2階）の平面図のとおりです。これに合わせて、家の中をつくってください。

- Archicad への命令は Tapir を使う（<KIT>/tapir_http.py の call(port, command, params)、port は 19723）。スクリプトは <KIT>/ に書いて実行する。
- 画面を見ている人に、家の中が1つずつできていく様子を見せる。作り始める前に ChangeWindow {windowType: 3DModel} で 3D を出し、最後までそのままにする。要素は **1つずつ別の命令で** 作り、1つ作るたびに time.sleep(0.6)。
- 作るもの（この順に。各段の前に何を作るかを日本語1行で書く）：
  1. 1階・2階の間仕切り壁（厚さ 120 前後）
  2. 内部の扉（開き戸・引戸。画像の向きに合わせる）
  3. 階段（1階から2階へ）。Tapir で階段が作れなければ、段の形のスラブで代える
  4. 部屋（ゾーン）。名前は画像の室名を使う
- 外壁・床・屋根・窓・玄関扉は変えない（間取りに合わせるための小さな調整が要るなら、何をなぜ変えたかを書く）。
- 最後に、この家の **通り芯** を1組だけ決めて、<KIT>/grid.json に書く（X と Y、それぞれ名前と座標 m。外壁・主要な間仕切りの芯に合わせる）。このあと全部の図面がこの通り芯を使う。
- 使ってよいのは、この指示・画像・rhino_house.py と、Archicad から読める情報だけ。スキル、記憶、過去の会話、session_search、honcho、delegate は使わない。
- 終わったら「完了」と、作ったものを3行以内で書く。
