# 10（まとめて）図面8枚を、1枚ずつ順に描く

この指示は公開キット用に新しく書いたものです。実験では、下の8本の指示を、実験者の AI エージェント（Hermes Agent）が1本ずつ**まっさらな新しい会話**で流し、1枚終わるごとに外から保存しました（`<KITROOT>/scripts/run_sheets.sh` と同じ形）。
キットのフォルダは `<KITROOT>/`、作業フォルダは `<KIT>/` です。

## ユーザーとの約束
返事はユーザーと同じ言語で、建築の言葉で短く。コマンド・パス・プログラム用語は見せない。コマンドは全部あなたが実行する。結果を作らない（描けていない図を「描けた」と言わない）。Archicad に命令を送るのは常に1つだけ。

## 前の段階が済んでいるか
- `<KIT>/progress.md` に 06_fix_model の完了があること。無ければ「work/prompts/06_fix_model.md を読んで、指示どおりに作業してください」を案内して止まる。
- `python <KITROOT>/scripts/check_connection.py` と `python <KITROOT>/scripts/check_grid.py` が OK であること。

## 描く順（どれも `<KIT>/prompts/` の中）
`10_sheet_P1`（1階平面図）→ `11_sheet_P2`（2階平面図）→ `12_sheet_SA`（A-A 断面図）→ `13_sheet_SB`（B-B 断面図）→ `14_sheet_ES`（南立面図）→ `15_sheet_EN`（北立面図）→ `16_sheet_EE`（東立面図）→ `17_sheet_EW`（西立面図）
目安：平面 12〜26分、断面 30〜35分、立面 14〜19分。8枚で約3時間。
`<KIT>/progress.md` で「完了・保存OK」になっている図は飛ばす（途中からの再開）。

## 流し方（使える方を選ぶ）
**方法A：1枚ずつ別の会話で流せる時（実験と同じ形。こちらを優先）**
あなたの環境に「指示を1つ受け取って、非対話で最後まで実行して終わる」AI のコマンドがある時（例：Claude Code の `claude -p --dangerously-skip-permissions`、Codex の `codex exec --full-auto`。書き方はそれぞれの説明書で確かめる）。
- ユーザーに「8枚を1枚ずつ、別の AI の作業として順に流します。権限の確認を省く設定で、このフォルダと Archicad だけを触ります。よろしいですか」と聞き、許可を得る。
- `<KITROOT>` で `SHEETS='<まだの図の名前を空白区切り>' AGENT_CMD='<コマンド>' bash scripts/run_sheets.sh` を実行（bash が無い時は、同じことを1枚ずつ：`<KIT>` で `<コマンド> "<KIT>/prompts/<名前>.md を読んで、指示どおりに作業してください。"` → `python <KITROOT>/scripts/check_connection.py --save`）。
- 1枚終わるたびに `<KIT>/logs/<名前>.txt` の最後を読み、「完了」とその図の内容をユーザーに1〜2行で伝え、progress.md に1行足す。

**方法B：方法Aが使えない時**
あなたが1枚ずつ自分で描く。1枚ごとに：
1. `<KIT>/prompts/<名前>.md` を読み、その指示を**その回の唯一の作業内容**として行う。前の図で読んだ値（高さ・寸法・座標）は使わず、モデルと grid.json から読み直す（実験では1枚＝1つの新しい会話だった。それに近づけるため）。
2. 指示の「使ってよいのは…だけ」を守る。指示の中の「session_search、honcho、delegate」は実験で使った AI の機能名で、「記憶や過去の会話、ほかの AI への丸投げを使わない」と読み替える。
3. 終わったら、指示の末尾「キットで足したこと」にある保存と記録を行い、ユーザーに1〜2行で伝える。**次の1行の案内は出さずに**、続けて次の図へ進む。
4. 会話が長くなって動きが不安定になったら、ユーザーに「ここで区切ります。新しい会話で、同じ1行『work/prompts/10_all_sheets.md を読んで、指示どおりに作業してください』を送ると、続きの図から描きます」と伝えて止まる。

## Archicad が落ちた時（保存に失敗した・つながらない）
ユーザーにこう頼んで待つ：
> Archicad が止まったようです。Archicad を開き直して、このフォルダの中の work フォルダにある「house_from_scratch」を開いてください（復元するか聞かれたら「いいえ」で、保存した所から始めます）。開いたら「できた」と送ってください。

開いたら、つながりを確かめ、その図を最初から流し直す（途中まで描いた 2D は、その指示の「済んでいる項目は飛ばす」に任せず、残っていれば平易に伝えてから続ける）。

## 8枚が終わったら
ユーザーに報告して止まる（3行以内）：8枚が描けたこと（描けなかった図があれば正直に）、そして次の1行：
> 次は新しい会話で：「work/prompts/18_rename_and_export.md を読んで、指示どおりに作業してください」
> 平面図の断面記号の名前を A・B にして（画面の操作が1つあります）、8枚を画像にします。
