# 00 準備：Archicad とつながっているかを確かめ、作業フォルダと空のプロジェクトを用意する

この指示は公開キット用に新しく書いたものです（実験では、実験者の AI エージェントがこの準備を直接行いました）。
あなた（AI エージェント）は、建築家のユーザーと一緒に、このキットで実験を再現します。
**キット**＝このファイルがある `prompts` フォルダの1つ上のフォルダです。下のコマンドは、キットのフォルダで実行します。

## ユーザーとの約束
- ユーザーは建築家で、プログラマーではありません。返事はユーザーと同じ言語で、建築の言葉で短く。コマンド・パス・プログラム用語は見せません（要る時はひとことで言い換える。例：「Archicad と AI がつながっているかの確認」）。
- コマンドは全部あなたが実行します。ユーザーに実行を頼みません。
- ユーザーに頼むのは画面の操作だけ。1回に1つ、メニューの場所まで書き、「終わったら『できた』と送ってください」と添えて待ちます。
- アプリが「コマンドを実行してよいか」を聞いてくる時は、「作業のために、このフォルダの中でプログラムを動かす許可です」と説明してよい。
- 結果を作りません。うまくいかない時は、何が起きたかを平易に伝えて止まります。

## 手順
1. **Python**：`python --version`（無ければ `python3`、`py -3`。`uv` があれば `uv run python` でもよい）。
   無い時は「作業に使う Python という道具が入っていません。入れてよいですか」と聞き、許可を得てから入れる。
   図の書き出しに Pillow と numpy を使うので、入っていなければ同じように許可を得て入れる（`pip install pillow numpy`。`uv` なら後で `uv run --with pillow --with numpy` で足りる）。
2. **Archicad とつながるか**：`python scripts/check_connection.py --scan`
   - `OK: Archicad JSON API` と `OK: Tapir アドオン` が出れば次へ（別のポートで見つかった時は、その番号が記録され、以後のスクリプトと指示が自動で使う）。
   - Archicad が見つからない時：まずユーザーに「Archicad を起動して、新しい空のプロジェクト（ファイル › 新規）を開いてください。開いたら『できた』と送ってください」と頼み、もう一度確かめる。
   - それでも見つからない、または Tapir が無いと出た時は、こう伝えて止まる：
     > Archicad と AI をつなぐ最初の準備が、まだ済んでいないようです。セットアップ資料 https://claude.ai/artifact/UwQrsxsWJztdwNVAd93t8T#ja のプロンプトをこのアプリに貼って準備を済ませ、Archicad を開き直してから、もう一度「prompts/00_prepare.md を読んで、指示どおりに作業してください」と送ってください。

     （ユーザーが英語で話している時は、資料の英語版 https://claude.ai/artifact/UwQrsxsWJztdwNVAd93t8T#en を案内する。）
3. **白紙か**：`python scripts/check_connection.py --count`
   - 「白紙：いいえ」なら、ユーザーに「今開いているプロジェクトに、すでに壁などがあります。Archicad で ファイル › 新規 › 新規プロジェクト を選び、空のプロジェクトを開いてください（今のプロジェクトは保存するか聞かれたら、必要に応じて保存してください）。開いたら『できた』と送ってください」と頼み、もう一度数える。
   - ほかのプロジェクトのファイルを開いたり変えたりしない。
4. **作業フォルダ**：`python scripts/prepare_workdir.py` → キットの中に `work/` ができる（指示・作図ルール・家のデータ・画像。指示の中の場所とポートは実際の値に置き換わる）。
5. **階を設定して、名前を付けて保存**：`python scripts/setup_stories.py work/house_from_scratch.pln`
   - 出力の階が 1FL（0）・2FL（3.15）・RFL（6.8）になったか、`work/house_from_scratch.pln` ができたかを確かめる。
   - 「Failed to change story height」などで階を変えられない時：空のプロジェクトを開き直してもらって（手順3の頼み方）、もう一度だけ流す。
   - ファイルができていない時（保存の命令が通らない版）：ユーザーに「Archicad で ファイル › 別名で保存 を選び、このキットのフォルダの中の work フォルダに、名前『house_from_scratch』で保存してください。終わったら『できた』と送ってください」と頼み、`python scripts/check_connection.py --save` で保存できるか確かめる。
6. **記録**：`work/progress.md` に「日時・00_prepare・完了・保存OK」を1行足す。
7. **ユーザーに報告して止まる**（3行以内）：準備ができたこと、そして次の1行：
   > 次は、新しい会話を始めて（作業フォルダは同じこのフォルダ）、次の1行を送ってください：
   > 「work/prompts/01_model_M.md を読んで、指示どおりに作業してください」
   > 家の外形を組みます（約15分）。作業中は Archicad の画面を触らないでください。
