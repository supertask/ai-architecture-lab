# Rhino の家を、白紙の Archicad に組む

Archicad で、空のプロジェクト「house_from_scratch」が開いています（壁も床も何もありません。階は 1FL・2FL・RFL だけ設定済み）。
<KIT>/rhino_house.py は Rhino で作った家（打放しと水盤の家・架空）のスクリプトです。見た目は <KIT>/rhino_house.png。
この家を、Archicad の壁・スラブ・窓・扉で組んでください。

- Archicad への命令は Tapir を使う（<KIT>/tapir_http.py の call(port, command, params)、port は 19723）。スクリプトは <KIT>/ に書いて実行する。
- 寸法は rhino_house.py の数字をそのまま使う（単位を m に直す）。外壁はコンクリート t200、外面＝ Rhino の外形。丸い角は丸い壁で。
- 作るもの：外壁（1階・2階）、2階の床、屋根（スラブ）、車庫、窓（スリット・凹みのガラス・帯窓・裏の掃き出し窓など）、玄関の扉、地面（GL）。部屋の間仕切りは作らない。
- 画面を見ている人に、家が1つずつ組み上がる様子を見せる。そのために：
  - 作り始める前に ChangeWindow {windowType: 3DModel} で 3D ウインドウを出し、最後までそのままにする（平面図に戻らない）。
  - 壁・スラブ・窓・扉は **1つずつ別の命令で** 作る（まとめて送らない）。1つ作るたびに FitInWindow を送り、0.6秒待つ（time.sleep(0.6)）。
  - 次の順に作る。各段の前に、何を作るかを日本語1行で書く。
    1. 1階の壁 → 2. 2階の壁 → 3. 床・屋根・地面 → 4. 窓・扉
- 最後は 3D ウインドウのまま FitInWindow して終える。
- Rhino の家と合っているかは数値で確かめる（寸法・高さ）。
- 終わったら「完了」と、作ったものを3行以内で書く。

- **家のデータ**：`<KIT>/rhino_house.py` は Rhino のスクリプトとして書かれているが、Rhino は要らない。中の数字（mm）を読んで使う。
