# 05 立面・断面の線を作る（人の画面操作が1つ入ります）

この指示は公開キット用に新しく書いたものです（実験では、実験者の AI エージェントが `make_sections.py` と同じことを行い、窓を開く操作は人が行いました）。
キットのフォルダは `<KITROOT>/`、作業フォルダは `<KIT>/` です。

## ユーザーとの約束
返事はユーザーと同じ言語で、建築の言葉で短く。コマンド・パス・プログラム用語は見せない。コマンドは全部あなたが実行する。ユーザーに頼むのは画面の操作だけで、1回に1つ、メニューの場所まで書いて「できた」を待つ。結果を作らない。

## 前の段階が済んでいるか
- `<KIT>/progress.md` に 01_model_M と 02_interior_I の完了があり、`<KIT>/grid.json` があること。無ければ「前の段階（家の外形・間取り）がまだ済んでいないようです」と伝え、足りない段階の1行（「work/prompts/01_model_M.md を読んで、指示どおりに作業してください」など）を案内して止まる。
- `python <KITROOT>/scripts/check_connection.py` でつながりを確かめる（NG なら「Archicad で house_from_scratch を開いてから、同じ1行をもう一度送ってください」と伝えて止まる）。

## 手順
1. `python <KITROOT>/scripts/make_sections.py create`
   - 外壁の範囲から、建物の外 3m に立面用の断面線4本（S南・S東・S北・S西）と、断面 A-A（y=3.0、東西に切る）・B-B（x=9.5、南北に切る）を作る。
   - 「壁がない」と出たら、01 が済んでいない。止めて伝える。
   - 注意：このプロジェクトの断面マーカーを全部消してから作る（再実行のため）。house_from_scratch 以外では流さない。
2. **ユーザーに頼む（画面の操作）**。この文をそのまま（ユーザーの言語で）送って待つ：
   > Archicad で、画面の左（または右）にある「ナビゲータ」の、いちばん上のボタン「プロジェクト一覧」を開いてください。その中の「断面図」のフォルダを開くと、6つ（S南・S東・S北・S西・A-A・B-B。頭に S-01 が付いています）があります。それぞれを1回ずつダブルクリックして開いてください（開くだけで、何もしなくて大丈夫です）。ナビゲータが見えない時は、メニューの ウィンドウ › パレット › ナビゲータ で出せます。終わったら「できた」と送ってください。

   理由：Archicad の版によっては、作ったばかりの断面の窓を AI からは開けない。人が1回開くと、以後は AI から切り替えられる。
3. 「できた」を受けたら `python <KITROOT>/scripts/check_connection.py --save`。
4. `python <KITROOT>/scripts/make_sections.py shoot` → `<KITROOT>/out/sections/` に6枚の画像。
   - 「開けない」「見つからない」と出た窓があれば、その名前を挙げて、手順2の操作をその窓だけもう一度頼む。
   - 画像を見て、立面4枚に家の外形が写っているか、A-A・B-B に切断面が出ているかを確かめる（真っ白・空なら、その窓をもう一度開いてもらう）。
5. `<KIT>/progress.md` に「日時・05_sections・完了・保存OK」を1行足す。
6. ユーザーに報告して止まる（3行以内）：立面・断面の線ができたこと、そして次の1行：
   > 次は新しい会話で：「work/prompts/06_fix_model.md を読んで、指示どおりに作業してください」
   > 断面に壁・床・屋根の層と基礎が出るように、モデルを直します（5〜15分）。
