# A-A 断面図を、実務の作図ルールで仕上げる

Archicad のプロジェクト「house_from_scratch」で、断面ウインドウ「S-01 A-A」を最初に ChangeWindow で開いてください（切断面と見えがかりはモデルから自動で出ています。壁・床・屋根は層のある部材なので、切断面に層が出ています。注記はまだありません）。
断面図の作図ルール（<KIT>/作図ルール_断面.md）に合わせて仕上げてください。

- Archicad への命令は Tapir を使う（<KIT>/tapir_http.py の call(port, command, params)、port は 19723）。スクリプトは <KIT>/ に書いて実行する。
- 足すもの：作図ルールの「必ず描くもの」1〜10。図名は「A-A 断面図」。切断面の上に塗りを重ねない。
- 高さの基準：GL＝敷地の上面（モデルの z=0）、1FL＝GL+100（モデルの z=0.1。ストーリー 1FL のレベル）。高さは全部 GL 基準で書き、1FL と GL は別の線にする。値はモデルから読む（前に描いた図の値は使わない）。
- GetElementsInDrawOrder は使わない（前回これの後に Archicad が落ちた）。重い読み取りは1回ずつ分けて送る。
- 通り芯は <KIT>/grid.json の1組だけを使う（自分で新しく決めない）。図面に出る通り芯の名前と位置を、ほかの図面とそろえるため。
- 横の寸法は、通り芯の外側（外壁の端まで）の寸法も入れ、合計を全長にそろえる。
- 種類ごとに分けて Archicad に送る（全部を1回で送らない）。送る前に、何を描くかを日本語1行で書く。
- 使ってよいのは上のルールファイル、<KIT>/grid.json と、Archicad から読める情報だけ。スキル、ほかのファイル、記憶、過去の会話、session_search、honcho、delegate は使わない。
- 壁・窓・スラブなどのモデルは変えない。2D の注記と塗りだけを足す。
- 終わったら「完了」と、描いたものを3行以内で書く。

## キットで足したこと（実験の指示文は上の線まで。以下は公開キット用の追記）

実験では、この前後の確認と保存を、指示の外から実験者の AI エージェント（Hermes Agent）が行いました。この1ファイルだけで同じ手順になるように、ここに書いておきます。上の「使ってよいのは…だけ」の決まりは、この節の確認・保存・記録には当てはまりません（作図・モデリングの中身には当てはまります）。

- **始める前**：`python <KITROOT>/scripts/check_connection.py` でつながりを確かめる。NG なら作業せず、ユーザーに「Archicad が開いていないか、つながっていません。Archicad で work フォルダの house_from_scratch を開いてから、同じ1行をもう一度送ってください」と伝えて止まる。
- **前の段階**：`<KIT>/progress.md` に 06_fix_model の完了が無い時は、「work/prompts/06_fix_model.md を読んで、指示どおりに作業してください」を先に案内して止まる。
- **やり直しの時**：この図にすでに注記がある（前に途中で止まった）時は、今ある 2D を読み、済んだ項目は飛ばして、足りない物だけを描く。
- **窓の名前**：上の「S-01 A-A」という表示名で見つからない時（参照ID を変えた後など）は、`GetDatabases` で type が Section、name が「A-A」の物を探し、その databaseId で ChangeWindow する。
- **終わったら**：`python <KITROOT>/scripts/check_connection.py --save` で保存し、`<KIT>/progress.md` に「日時・12_sheet_SA・完了（または途中）・保存OK」を1行足す。
- **保存に失敗したら**（Archicad が落ちた可能性）：ユーザーに「Archicad が止まったようです。Archicad を開き直して、このフォルダの中の work フォルダにある「house_from_scratch」を開いてください（復元するか聞かれたら「いいえ」）。開いたら、新しい会話で同じ1行をもう一度送ってください」と伝えて止まる。
- **ユーザーへの最後の返事**：ユーザーと同じ言語で、建築の言葉で短く（コマンドやファイルの中身を見せない）。上の「完了」と3行に加えて、次に送る1行を書く：
  > 次は新しい会話で：「work/prompts/13_sheet_SB.md を読んで、指示どおりに作業してください」
  > B-B 断面図を描きます（30〜35分）。
- `<KITROOT>/prompts/10_all_sheets.md` から呼ばれて続けて描いている時は、次の1行の案内は出さずに戻る。
