# A-A 断面図を直す（3回目）

Archicad のプロジェクト「house_from_scratch」で、断面ウインドウ「S-01 A-A」を最初に ChangeWindow で開いてください。前回までに AI がこの図に注記を描き、1回直しました。2回目の点検で残った問題を、下のとおり直してください。

- Archicad への命令は Tapir を使う（<KIT>/tapir_http.py の call(port, command, params)、port は 19723）。スクリプトは <KIT>/ に書いて実行する。
- 作図ルール：<KIT>/作図ルール_断面.md（迷ったらこれに従う）。通り芯は <KIT>/grid.json。
- 高さの基準：GL＝モデルの z=0、1FL＝GL+100。値はモデルから読む。
- 既にある 2D 要素は、直す物だけを動かす・消す・描き直す。正しい物は残す。
- GetElementsInDrawOrder は使わない（Archicad が落ちたことがある）。重い読み取りは1回ずつ分けて送る。
- 送る前に、何を直すかを日本語1行で書く。直したら、その場所の要素の座標を読み直して、重なりが無くなったことを数値で確かめる。
- 使ってよいのは、この指示、ルールファイル、grid.json と Archicad から読める情報だけ。スキル、ほかのファイル、記憶、過去の会話、session_search、honcho、delegate は使わない。
- 壁・窓・スラブなどのモデルは変えない。
- 終わったら「完了」と、直したものを箇条書き5行以内で書く。

## 直すこと（重要な順）
1. 【2階床】の層構成注記が、扉の見えがかりの線・一点鎖線と重なっている。LDK の右側の空いた所（扉・通り芯・寸法・CH から 0.3m 以上離れた所）へ移し、引出線は斜めに1回折る。
2. 【屋根】の引出線が垂直で、箱の壁と X4 の通り芯に平行に走り壁の線に見える。注記を右へ 0.6m ほど移し、斜めに1回折って屋根の上面に当てる。
3. 最上部の屋根（最高高さ GL+7600 の箱の上面、X1 の頭）にも防水の青線が無い。箱の上面は外に出ている屋根なので、切断された屋根スラブの RC の上面（上端から 0.10 下）に青線を引き、縁に立上りがあれば内側を上げて笠木の下で止める。箱の上に笠木が描かれていなければ、細線で笠木を足す（B-B の箱と同じ描き方にそろえる）。
4. 箱の中（閉じた空間）には青線を引かない。
5. X5〜X6 の基礎に入っている縦の継ぎ目の線が AI の描いた線なら消す。
