# 1階平面図を直す（2回目）

Archicad のプロジェクト「house_from_scratch」で、平面図を ChangeWindow（windowType FloorPlan, storyIndex 0）で開いてください。前回 AI がこの図に注記を描きました。実務の図面の描き方（作法）と比べて見つかった問題を、下のとおり直してください。

- Archicad への命令は Tapir を使う（<KIT>/tapir_http.py の call(port, command, params)、port は 19723）。スクリプトは <KIT>/ に書いて実行する。
- 作図ルール：<KIT>/作図ルール_平面.md（迷ったらこれに従う）。通り芯は <KIT>/grid.json。
- 高さの基準：GL＝モデルの z=0、1FL＝GL+100。値はモデルから読む。
- 既にある 2D 要素は、直す物だけを動かす・消す・描き直す。正しい物は残す。
- GetElementsInDrawOrder は使わない（Archicad が落ちたことがある）。重い読み取りは1回ずつ分けて送る。
- 送る前に、何を直すかを日本語1行で書く。直したら、その場所の要素の座標を読み直して、重なりが無くなったことを数値で確かめる。
- 使ってよいのは、この指示、ルールファイル、grid.json と Archicad から読める情報だけ。スキル、ほかのファイル、記憶、過去の会話、session_search、honcho、delegate は使わない。
- 壁・窓・スラブなどのモデルは変えない。
- 終わったら「完了」と、直したものを箇条書き5行以内で書く。

## 直すこと（重要な順）
0. 前回の作業は時間切れで途中で止まった。まず今の状態を読んで、下の項目のうち済んでいる物は飛ばす。
0-2. 室名を2階平面図と同じ形にそろえる：室名だけの Text（3mm、黒）と、面積・帖の2行の Text（2.5mm、黒）の2つに分けて作り直す（今は3行を1つの Text にしていて、大きさが部屋ごとに違う）。2階の室名（floorIndex 1 の Text）を読んで、同じ大きさ・ペン・行間にする。面積・帖が入らない小さい部屋は室名だけでよい。
1. 室名の文字：大きさと色をそろえる（全部黒、室名 3mm、面積・帖 2.5mm 程度）。青・橙の文字は黒にする。
2. 室名・面積・建具記号が、通り芯の一点鎖線・壁・扉の開き・階段・ほかの文字と重なっている所を、空いた所へ 0.15〜0.3m 動かす（通り芯の線も障害物として扱う）。
3. 断面の印（切断線）の近くの建具記号・文字は、切断線から 0.2m 以上離す。
4. 車庫の床は GL±0（土間）、ほかの部屋の床は 1FL=GL+100。車庫の室名の下の高さの書き込みが合っているか確かめ、違えば直す。
5. 階段の「UP」矢印の代わりに、上り始めに「UP」の文字は残してよいが、各段に小さい段番号（1.8mm）を付ける。
