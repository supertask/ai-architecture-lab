# 18 地中の画層を分けて、8枚を画像に書き出す：スクリプトを順に流す

キットのフォルダで、次のスクリプトをこの順に1本ずつ流してください。

1. `python <KITROOT>/scripts/layer_found.py`
2. `python <KITROOT>/scripts/export_png.py`

- 1本ごとに、出力をそのまま見せる。
- エラーが出たら（終了コードが 0 でない時も）、そこで止めて、出力をそのまま報告する。直そうとしたり、先へ進んだり、同じスクリプトを流し直したりしない（`layer_found.py` は2回流すと壁の下端が2回下がる）。
- これ以外の作業はしない。
