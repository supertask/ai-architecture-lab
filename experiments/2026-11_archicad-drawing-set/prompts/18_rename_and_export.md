# 18 断面記号の名前を A・B にして、8枚を画像に書き出す（人の画面操作が1つ入ります）

この指示は公開キット用に新しく書いたものです（実験では、名前の変更は実験者の AI エージェントが Archicad の画面で行い、書き出しは `export_png.py` と同じ処理で行いました）。
キットのフォルダは `<KITROOT>/`、作業フォルダは `<KIT>/` です。

## ユーザーとの約束
返事はユーザーと同じ言語で、建築の言葉で短く。コマンド・パス・プログラム用語は見せない。コマンドは全部あなたが実行する。ユーザーに頼むのは画面の操作だけ。結果を作らない。

## 前の段階が済んでいるか
- `<KIT>/progress.md` で 10_sheet_P1〜17_sheet_EW が完了していること。まだの図があれば、その名前を伝え、「work/prompts/10_all_sheets.md を読んで、指示どおりに作業してください」を案内して止まる（ユーザーが「描けた所までで進めて」と言えば進めてよい）。
- `python <KITROOT>/scripts/check_connection.py` が OK であること。

## 手順
1. **ユーザーに頼む（画面の操作）**。この文をそのまま（ユーザーの言語で）送って待つ：
   > 平面図に出る断面記号の名前を A・B にします。Archicad のナビゲータの「プロジェクト一覧」→「断面図」で、「S-01 A-A」を右クリックして「断面図の名前を変更...」（版によっては「断面図設定」）を選び、参照ID の欄を「S-01」から「A」に変えて OK を押してください。「S-01 B-B」も同じように参照ID を「B」にしてください。終わったら「できた」と送ってください。

   （参照ID は AI からは変えられない。変えると窓の表示名（参照ID ＋ 名前）が変わるが、スクリプトは名前「A-A」で探すので影響しない。）
2. `python <KITROOT>/scripts/check_connection.py --save`
3. 書き出す：`<KITROOT>` で `python scripts/export_png.py`（Pillow・numpy が要る。無ければ `uv run --with pillow --with numpy python scripts/export_png.py`）→ `<KITROOT>/out/png/hi_P1.png` など8枚と、各図の文字（texts_*.json）。
   - 「見つからない断面の窓」「真っ白」と出た図があれば、その窓をナビゲータで1回開いてもらってから、その図だけ書き出し直す（`python scripts/export_png.py SA` のように）。
4. 画像を開いて、8枚それぞれに図が写っているか、立面・断面で GL の線が1本につながっているか（貼り合わせのずれが無いか）を確かめる。
5. `<KIT>/progress.md` に1行足す。
6. ユーザーに報告して止まる（4行以内）：
   - 8枚の画像の置き場所（「このフォルダの out の中の png フォルダ。hi_ で始まる8枚」）
   - 目についた所があれば1〜2件
   - 次の1行：
   > 次は新しい会話で：「work/prompts/30_inspect_and_fix.md を読んで、指示どおりに作業してください」
   > AI が図を点検して、直す所を挙げてから描き直します（1回 約1〜1.5時間）。自分で気づいた所があれば、この1行のあとに、ふつうの言葉で書き足してください。
