# 06 モデルを直す：壁・床・屋根に層を入れ、基礎を足し、1FL を GL+100 にする

この指示は公開キット用に新しく書いたものです。実験では、最初に描いた断面図が「屋根は厚さ約1mの塊、基礎なし、壁に層なし」で弱かったため、実験者の AI エージェント（Hermes Agent）が下のスクリプトと同じ処理でモデルを直しました（`<KITROOT>/TECHNICAL.md` の「モデルの直し」）。
キットのフォルダは `<KITROOT>/`、作業フォルダは `<KIT>/` です。スクリプトは `<KITROOT>/scripts/` で実行します（直す前の控えなどを同じフォルダに書きます）。

## ユーザーとの約束
返事はユーザーと同じ言語で、建築の言葉で短く。コマンド・パス・プログラム用語は見せない。コマンドは全部あなたが実行する。結果を作らない。命令は1本ずつ送り、前のスクリプトが終わってから次を流す。

## 前の段階が済んでいるか
- `<KIT>/progress.md` に 05_sections の完了があること（無ければ「work/prompts/05_sections.md を読んで、指示どおりに作業してください」を案内して止まる）。
- `python check_connection.py` でつながりを確かめる。

## 手順（`<KITROOT>/scripts/` で、この順に1本ずつ。どれかが失敗したら、そこで止めて原因を調べる）
0. **途中からの再開か**：`<KIT>/progress.md` に 06 の途中の記録があれば、済んだ手順を飛ばす。特に `fixA_raise.py` は2回流すと2回上がる。`walls_before_fixA.json` がすでにあれば `fixA_snapshot.py` は流さない。
1. **屋根を突き抜けた壁が無いか**：平面図（1階）に切り替えて、全部の壁とスラブの `Get3DBoundingBoxes` を読み、壁の上端がいちばん高いスラブの上端より上にある物を探す。間仕切り（厚さ 0.15 未満）なら、その上のスラブの下端までの高さに直す（実験では1枚あった。`<KIT>/prompts/04_fix_partition_F.md` の1と同じ直し）。外壁は変えない。
2. **前に描いた 2D があるか**：`python fixA_del2d.py`（数えるだけ）。0 でなければ、ユーザーに「前に描いた図の線や文字が残っています。モデルを直すと合わなくなるので消して描き直します」と伝えてから `python fixA_del2d.py --apply`。
3. `python fixA_snapshot.py` — 直す前の壁の控え
4. `python fixA_comps.py` — 層の組み合わせ（複合構造）を7種作る。材料は日本語の標準テンプレートの番号で選んでいる。エラーになったら止め、ユーザーに「材料の名前が実験の時と違うテンプレートのようです」と伝える。
5. `python fixA_walls.py` — 壁を層付きに（外壁は、部屋のある側を室内側にする）。最後の「成功数 / 全数」が同じか確かめる。
6. `python fixA_slabs.py` — **計画を表示するだけ**。振り分け（0・1・1a・2・3・4）がスクリプト先頭の規則に合っているかを確かめる。実験の家では 0 が3枚、1 が2枚、1a が1枚、2 が3枚、3 が2枚、4 が1枚。
   - 大きく違う時は進めず、ユーザーに「屋根と床の直し方が、実験の家と違う形になりそうです」と内容を平易に説明し、進めてよいかを聞く。
7. `python fixA_slabs.py --apply` → `python check_connection.py --save`
8. `python fixA_found.py` — 1階の床（部屋ごと。車庫は土間コンクリート、水盤は除く）と基礎
9. `python fixA_raise.py` — 家ごと +0.1（1FL＝GL+100）。最後に表示される最高・最低の高さを控える（実験では最高 GL+7600、最低 GL-850）。
10. `python layer_found.py` — 地中の部材を専用の画層へ、1階の外壁の下端を GL へ。最後に保存される。
11. `python check_connection.py --save` → `python make_sections.py shoot` → `<KITROOT>/out/sections/05_section_AA.png` を見て、切断面に壁・床・屋根の層と基礎が出たかを確かめる（`<KITROOT>/results/sa_before_after.jpg` の下半分が目安。注記はまだ無くてよい）。
12. 1手順終わるごとに `<KIT>/progress.md` に「日時・06・手順番号・結果」を1行足す。
13. ユーザーに報告して止まる（3行以内）：直したこと（層・基礎・高さ）、そして次の1行：
    > 次は新しい会話で：「work/prompts/10_all_sheets.md を読んで、指示どおりに作業してください」
    > 8枚の図面を1枚ずつ描きます（全部で約3時間。1枚ずつ頼みたい時は「work/prompts/10_sheet_P1.md を読んで、指示どおりに作業してください」から順に）。

## うまくいかない時
- スクリプトが Archicad のエラーで止まった：エラーの1行目を平易に言い換えて伝え、`python check_connection.py` でつながりを確かめる。落ちていたら、ユーザーに「Archicad を開き直して、作業フォルダの house_from_scratch を開いてください（復元を聞かれたら『いいえ』）」と頼み、progress.md を見て続きから。
- 層が断面に出ない：断面の窓の表示（モデル表示の設定）で複合構造が簡略表示になっていないかを疑う。設定の変更はユーザーに頼まず、まず状態を伝える。
