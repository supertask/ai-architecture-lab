# 平面図の作図ルール（実務の図面の描き方から抽出）

## 見方・前提
- 実務の図面の描き方（作法）を、図の種類ごとに整理したもの。形・間取り・数値は写していない。
- 公開版では、元にした図面の枚数・件数（n/N）と、図枠の様式の内訳を外した。
- 「推測」と書いたものは画像から確証を取れていない。

---

## 平面図（1:100〜1:50の一般平面図。詳細図でないもの）

### 共通の決まり
- **図枠は下端に全幅の横帯1本**。図名・縮尺は図枠の DRAWING TITLE / SCALE 欄に入れる。
- **通り芯は細いグレーの一点鎖線で、建物の外まで、寸法線群のさらに外まで延ばす**。
- **通り芯符号は細線の円に「X1」「Y1」のように英字＋数字**。符号を付けるのは**片側の2辺だけ**。X は左→右、Y は下→上に増える。
- **寸法は mm・単位なし・3桁カンマ区切り、端部は小さな黒丸**。縦寸法の文字は90°回転させて線の左側に置く。
- **外周寸法は「通り芯間」＋「全長」の2段が基本**。入れる辺は2辺（下＋左 か 下＋右）が多い。
- **室名は室のほぼ中央**、面積を併記する時は「室名／面積 ㎡／帖」の縦3行・中央揃え。
- **開き戸＝扉線＋1/4円弧（細線）、引戸＝ずらした平行線**。
- **上部のもの（バルコニー・庇）は細い破線＋「▽上部バルコニー」「△上部庇」のように三角付きの名前**。三角の向きで線のどちら側かを示す。
- **色は基本モノクロ**。床だけ淡い塗り（木床＝淡ベージュ＋張り方向の細線、水回り・タイル＝淡グレー＋格子）。法規線（延焼ライン）は赤またはオレンジ。
- 家具・設備は描き込む（便器・洗面・キッチン・洗濯機は実線、ベッド・ソファ等の置き家具は破線または細線）。

### ばらつき（どちらでもよい）
- 1枚に何図: 全階を1枚に並べる（1:100で2段組・通り芯位置を上下左右で揃える）／1階ごと1枚。複数図の時だけ各図の下に図名（右下または下中央、太字）を入れる。
- 帖の書き方: 「○○帖」が多い。「○J」もある。面積を書かない図もある（確認申請用など）。
- 室名を細枠で囲む、CH＝を室名の下に入れる、という書き方もある。
- 床レベル: 枠囲みの相対値（「±0」「-30」）／「1FL±0」形式／なし。
- 方位記号: 円＋黒三角＋N を余白に1つ／「真北」の文字と線だけ／なし。
- 階段: 段番号（1,2,3…）を振り破断線で切る（UP矢印は使わない）書き方が多い。階段の幅・蹴上・踏面・段数を文字でまとめる図もある。
- 主出入口に三角マーク（赤▲・黒▲・◀◀）を置く図もある。

### Archicadでの出し方
- 通り芯: **通り芯ツール（グリッド）**。符号は円、表示は片端のみ、線種は一点鎖線・グレーの細ペン。名前は「X」「Y」接頭辞＋連番。延長量は「寸法線の外まで」になるよう線の長さを手で伸ばす。
- 外周寸法: **寸法ツールの連続寸法（直線寸法）**で、通り芯間の段と全長の段を別チェーンで置く。自動にするなら「自動寸法 → 外部寸法」で出して不要段を消す。マーカーは**黒丸（塗りつぶし円）**、文字は線の上・中央。桁区切りは環境設定の寸法・作業単位側（設定場所は推測、要確認）。
- 室名: **ゾーン＋ゾーンスタンプ**。スタンプに「名前／面積（小数2桁 ㎡）／帖」を3行。帖はプロパティ式（面積÷1.62 など、係数は要確認＝推測）で作る。
- 床の淡色: ゾーンのカテゴリ塗り、またはスラブ（床仕上）の表面塗り＋張り方向パターン。木床と水回りで塗りを分ける。
- 上部の破線: 上階スラブ/屋根を「関連する全てのフロア」表示＋オーバーヘッド線を破線に。名前は**ラベル**か文字＋▽△。
- 置き家具の破線: 家具オブジェクトのレイヤーを分け、**グラフィックオーバーライド**で破線・細ペンに。
- ペン: 切断＞見えがかり＞仕上・目地＞寸法・通り芯 の4段のペンセットを用意し、延焼ライン用に赤/オレンジのペンを1本。

### チェックリスト
- [ ] 通り芯の符号は2辺だけ、X左→右・Y下→上になっているか
- [ ] 通り芯線は寸法線の外まで出ているか（一点鎖線・グレー）
- [ ] 外周寸法は「芯々」と「全長」の2段で、端部が黒丸、カンマ区切り、単位なしか
- [ ] 室名・面積（㎡）・帖が中央に3行で揃っているか
- [ ] 上部のバルコニー・庇は破線＋▽/△付きの名前になっているか
- [ ] 床の塗りは淡色2〜3種類までに抑えているか（木床・水回り・外部）
- [ ] 図名と縮尺は図枠に入っているか（複数図なら各図の下にも図名）
- [ ] 置き家具は破線/細線、造作・衛生器具は実線になっているか


## 寸法・通り芯・室名・建具（全図共通）

### 寸法
- 単位 mm・単位記号なし・3桁カンマ区切り。
- **端部は小さな黒丸**。斜線ティック・矢印は使わない。既存メモの「黒丸または斜線」は「黒丸」に統一してよい。
- 文字は寸法線の上・区間中央。縦寸法は90°回転して線の左側。小区間は端に寄せる。
- 外周: 1:100は「芯々＋全長」の2段、1:50前後の詳細図は「部分＋芯々＋全長」の3段。段の間隔は揃える。
- 室内: 内法・有効・開口幅を記号付き（W、D、WD=、有効、L、R）で直接。円弧は R○○。
- 斜めの壁は壁に平行な寸法線で。角度は「22.5°」「45°」「30°」と書く。
- 法規検討の寸法（離れ・斜線距離）だけ色（赤/青）を変える図がある。

### 通り芯
- 細いグレーの一点鎖線。寸法線群の外まで延ばす。
- 符号: 細線の円に「X1」「Y1」。X左→右、Y下→上。
- 符号は**2辺だけ**（下＋左、下＋右、上＋右、など。図面一式で固定）。全図（平面・詳細・天井伏・屋根伏）で同じ辺・同じ名前を使う。
- 補助芯: 「X3a」「Y4a」の英小文字か「X5.5」の小数。斜め方向は別系統（A・B、UX1…）。
- 符号が近接する時は引出線で千鳥に逃がす。基準にする芯だけ太い円にする書き方もある。
- 1:100の簡易図では、符号を使わず端部を黒丸だけにすることもある。

### 室名
- 室のほぼ中央、中央揃え。
- 平面図・平面詳細図: 「室名／○.○○ ㎡／○.○○ 帖」の3行（多数）。数字と単位の間に半角スペース。
- 天井伏図（入れる場合）: 「室名／CH=○○○○」の2行。
- 収納は「収納＋階＋連番」で名前を付ける。
- 文字の大きさは寸法文字の約1.3〜1.5倍、室名と数値は同じ大きさ。
- 室名を枠囲みにするのは少数。外部（テラス）だけ枠囲みにする図もある。

### 建具記号
- **円を横線で上下2分割、上＝種別、下＝番号（階-連番：1-1, 2-3）**。
- 種別記号: AW（アルミ）、WD（木製）、SD（鋼製）を基本に、TGD・AD・SW・CD・FD・STD。
- 家具・建具詳細・ガラリ等の参照は細線の**四角タグ**（D-1、D-5-1、F-2、WG-1）。建具記号の近くに置く。
- 1:100の平面図では記号を省くことがある、窓だけ（AW）付ける図もある。
- FIX・防火設備・品番は記号の脇に文字で補う。

### 方位・縮尺・図名・図枠
- 図枠は下端の全幅横帯。欄の例: 設計者名・登録 → DRAWN/CHECKED/APPROVED → PROJECT TITLE → SUBMISSION & REVISION → DRAWING TITLE/SCALE → DRAWING No./DATE。欄見出しは英字大文字。
- 縮尺は図枠の SCALE 欄に一括、「1:50(A3)」のように用紙サイズ付き（複数縮尺は「1:40, 1:30(A2)」）。
- 図名: 1枚1図なら図枠だけ。複数図なら各図の下（中央か右下）にも図名、天井伏図などは枠囲み＋縮尺。
- 方位記号: 決まった形はない。多いのは「円＋黒三角＋N（真北へ回転）」で、余白（左上・左下）に1つ。展開方向キー（菱形にA〜D）を方位の隣に置く図もある。
- 改訂: 赤字で改訂欄、または図内に赤枠メモ。
