# 立面図（実務の描き方）

> 描いたら、数値の点検 → 画像を見た点検の順で確かめてから見せる。

## 手順（開いている立面ウインドウに 2D の注記と塗りだけを足す。確認済み）
1. 状態を読む：GetCurrentWindowType（Section のはず）、GetStories、GetCurrentWindowDrawingScale（文字の高さは紙の mm）、ペン表（GetCurrentPenTable で attributeId → GetPenTables `{"attributeIds":[{"attributeId":…}]}`。引数なし・`penTables` キーは schema エラー）で 224〜255 の 実務 ペンが既にあるか。既にあればペンは触らない。線種（一点鎖線・通り芯）と塗り（`100 %` Solid）の GUID は API.GetAttributesByType＋API.GetLine/FillAttributes で名前から引く。
2. モデルを読む：**API.GetElementsByType**（Wall/Slab/Window/Door）→ API.Get3DBoundingBoxes（`elements` は `[{"elementId":…}]` の形）＋ Tapir GetDetailsOfElements をファイル（model.json）に保存し、以後はそれから計算する。Tapir の GetElementsByType は断面ウインドウでは 2D 要素しか返さない（壁 0 件に見える）。details の `id` は要素 ID 文字列なので GUID は GetElementsByType の順で対応させる。
3. 座標の確認：テスト円を2つ（原点と建物の対角）描いて SaveCurrentWindowAsImage（entireDrawing）→ vision で位置を確かめ、すぐ消す。南面は x＝モデル x、y＝モデル z。
4. 高さはモデルから：GL＝敷地の地面スラブ上端、最高高さ＝壁・スラブの最大 zMax、軒高＝それより下の屋根スラブ上端、各 FL＝階の level。表記は `round((z-GL)*1000)`。
5. 種類ごとに分けて送る（壁の塗り→ガラス→GL→レベル→高さ寸法→通り芯→横の寸法→図名）。送る前に何を描くかを1行書く。作った GUID を種類名ごとに created.json に記録し、再送はその種類だけ DeleteElements してから作り直す。
6. 点検：SaveCurrentWindowAsImage → 縮小画像は小さいので PIL で部分を切り出し拡大して vision。位置（塗りの切れ目・線の始点が文字の左端より外か等）は vision に聞かず、画素の行スキャン（1行の RGB を x と m 換算で並べる／濃い画素を # の ASCII にする）で判定する。vision は「線が短い」「数字が重なる」を実際と違って報告することがある。px/m は座標確認のテスト円2つから求める。最後にモデル（壁・スラブ・窓・扉の数と bbox）を読み直し手順2と一致、窓内の 2D 要素数＝created.json の合計を確かめる。

面の計算（model.json → 壁の塗り（奥→手前）とガラスの見える部分）は、下の手順で行う。

### 塗りの作り方（画家のアルゴリズム）
- 面を（奥行き y, 矩形）で集め、**奥→手前の順**に CreateHatches する（後から作った塗りが上に重なる）。対象：x 方向の壁の南面、y 方向の壁の南の端面、スラブの南向きの縁（ポリゴンの外向き法線の y 成分＜-0.3）、丸い壁の外側面と北向きの丸い壁の内側面（開口越しに見える）。GL より下は切る。厚さ 0.15 以下の間仕切り・敷地の地面スラブ・階段の段板は除く。
- 開口は **x 方向の壁だけ**矩形から引く（y 方向の壁の端面から窓を引くと、西向きの窓で端面に穴が開く）。扉は白（ペン255）の面を壁と同じ奥行きで足す（引くだけだと奥の壁が扉の穴から透ける）。
- 手前の面（窓の矩形を含む）で完全に隠れる面は送らない（数百枚→半分程度）。ガラスの「半分以上隠れる」判定でも、手前の窓を遮るものに数える（数えないと南の窓越しに北の窓が見える扱いになる）。
- 丸い縁のスラブも法線の南向き成分でペン 226〜249 を選ぶ（225 一様にすると丸い壁の帯の上に明るい横縞が出る）。
- ガラスは CreateHatches の foregroundColor/backgroundColor に RGB を直接渡せる（ペン表を変えなくてよい）。丸い壁の中の平らなガラスは幅×|sin φ| の投影幅で描く。反射線は幅 0.8m 未満のガラスには入れない（詰まる）。反射線は窓の左寄り（幅の 12%・22% から、長さ≦幅の15%）に置く：連窓は1枚のガラス矩形なので中央付近に置くと中桟をまたぐ。
- CreateHatches は単一輪郭で穴を持てない。開口を「引く」のは矩形の分割（引き算で残りを上下左右の矩形に割る）で作る。
- ガラスは壁と別の種類で後から送るので、画家の順序に頼らず「手前の面で引いた見える部分」だけを送る（手前の壁より上に乗らない）。その時、丸い壁の窓は**持ち主の壁の帯を遮るものから除く**：帯の奥行き（端点の最小 y）が窓より手前になり、ガラスが半分以上削られて白・灰の縦縞になる。

### 注記の置き方（1:100、文字 2.5mm）
- 左から：レベル文字（右揃えの端 x≈-2.4m）→外の寸法列（全高）x≈-1.8→内の列（分割）x≈-1.0→建物。レベルの一点鎖線は建物の外だけ（左は文字の外端〜建物の 0.3m 手前、右は建物の 0.3m 先〜図の端）。建物を横切ると外形線を隠す。
- 文字の大きさはモデル単位で H＝紙の mm×縮尺/1000（1:100 の 2.5mm＝0.25m。/100 と書くと1桁小さくなり、線の始点が文字の中に入る）。字幅の見積もりは全角 1.35H・半角 0.8H（画像で実測）。レベル線の左端＝右揃え端 − 字幅 − 0.1m。
- 黒丸は 12 角形の小さな塗り（r=0.05m、黒）。寸法の数字は angle=π/2・anchor MiddleBottom で線の左に置く。0.5m 未満の区間（GL→1FL の 150 など）は数字を区間の外（下 0.3m）へ出す（GL の太線と重なる）。
- 通り芯は y 方向の厚さ 0.2 以上・高さ 3m 以上の壁の芯から取り、1m 以内に並ぶ芯は外側の1本にする。横の寸法は 1段目＝通り芯間、2段目＝建物の外面の全長（通り芯間の合計と一致しなくてよい）。記号は2段目の下。
- 図名は CreateTexts の style.usedContour=True・contourOffset で枠を付ける（AC26 は四角枠だけ）。

## Archicad 26 で確認済みの出し方（2026-11-14、架空の家の南立面図で通した）
- 白黒：テンプレートのペンセット「02 意匠設計_グレースケール」を「01 意匠設計」に上書きして有効にする（CreatePenTables overwrite、sourceAttributeId）。上書きの前に「01 意匠設計_作業色(控え)」へ複製して残す。isActiveForModel だけでは窓の表示が変わらなかった。グレースケール版にも色付きのペンが14本残る→明るさを保った灰色に直す。
- 線の太さ用に 250（0.50 GL）・251（0.25 外形）・252（0.13 細線）・253（0.10 灰 レベル・寸法・通り芯）・255（白）を足す。
- 階の表示（RFL/2FL の▽）は階の dispOnSections=False（SetStories は index を先頭だけに付ける。2回目以降は Failed to change story height になるので、作る時に False にする）。
- GL：地面スラブの上端＝GL（1FL より下、例 1FL=GL+150）、厚み 0.02 にすると立面の断面線で太線1本に見える。2D の白い塗りで GL の下を隠す方法は効かない（断面ウインドウでは 2D の塗りがモデルの線の下に描かれる）。地面の下に何も見えないよう、外壁の足元・水盤も地面の下端にそろえる。
- Tapir のコマンドの引数が分からない時は ArchicadTapir MCP の archicad_get_command_schema で調べる。名前は MCP 側の名前（`elements_create_hatches` など。archicad_list_commands の一覧を検索）で、tapir_http.call に渡すのは CamelCase（CreateHatches）。CamelCase 名で schema を3回引くと MCP が約60秒止まる。
- 注記は断面ウインドウに切り替えてから CreateTexts/CreateLineElements/CreateCircles（座標は x＝モデルの x（南面）、y＝高さ）。その窓の中の Text/Line/Circle は GetElementsByType で取れるので、再実行時は消してから描く。GetDetailsOfElements は断面ウインドウの要素を読めない。
- 通り芯の丸は CreateCircles（AC26 の文字枠は四角だけ）。通り芯の線は GL より下だけにする（建物の上まで通すと、通り芯と同じ位置の外形線を隠す）。平面の通り芯要素（CreateGridElements の既定）は立面に実線で長く出たので、立面には使っていない。
- 寸法は今は 2D の線と文字（モデルを変えても追従しない）。連動が要る回は寸法ツール（CreateAssociativeDimensionsOnSection など）に置き換える。
- 落とし穴：壁の下端を下げると、窓・扉の sillHeight は壁の下端から測られるため開口ごと下がる。足元を延ばすときは別の「足元の壁」を足す。直したら Get3DBoundingBoxes で開口の zMin を確かめる。
- 平面の注記（2026-11-14 確認）：2D 要素の階は指定必須（CreateTexts・CreateAssociativeDimensions＝floorIndex、線・円・塗り＝floorInd）。ChangeWindow だけだと2階の注記が1階に作られた。寸法は CreateAssociativeDimensions に coordinate だけの点で作れる（テンプレート既定で端部黒丸・カンマ区切り＝実務 と同じ）。室名は layout の Text を SetDetailsOfElements の position で動かし、壁・扉の開き・階段・他の文字との重なり面積が最小の位置を探す（収まらなければ名前を2行に）。立面用の切断線は平面に出るので非表示レイヤーへ（CutPlane は詳細も 3D 範囲も API で取れない→作った順で見分ける）。保存画像は SetZoom の余白を大きく取り、書き出し後に余白を切る。

## 立面図

### 共通の決まり
- **図名**
  - 各面の下（通り芯記号よりさらに下）に置き、細い矩形枠で囲む。
  - 図名には縮尺を書かない。縮尺は図枠の SCALE 欄に一括（例の書式：`1:100(A3)`）。
- **面数と配置**
  - 1枚に2〜4面。2面なら横一列、4面なら2×2。
- **色**
  - 線は基本モノクロ（黒〜グレー）。
  - 壁面は薄グレーのベタ塗り。曲面や斜めの面には**グレーのグラデーション**（陰影付きの見えがかり塗り）。
- **GL**
  - 建物幅より左右に長く伸ばした**最太の実線1本**。
- **レベル表記**
  - 細い一点鎖線（グレー）を建物の外、図の幅いっぱいまで伸ばす。
  - 文字は寸法列のさらに外側に縦一列で並べる。
  - 書式は `▽名称=GL+数値`（詳しくは最後の「レベル・高さ表記」）。
- **高さ寸法**
  - レベル文字と同じ側に、縦寸法を2列以上並べる。
  - 内側の列：階ごとの分割寸法。外側の列：最高高さまでの全高。
  - 端部は黒丸。数字は3桁カンマ区切り、90°回転。
- **通り芯**
  - 丸囲み記号で、図の**下側**（水平寸法の下）に置く。芯線は細い一点鎖線で上まで通す。
  - 水平寸法は2段：通り芯間と、全長・境界線までの離れ。
- **ガラス**
  - 薄い青紫（ラベンダー）のベタ塗りに、斜めの反射線を2〜3本入れる。
  - FIX は文字で書く。引違いは矢印、すべり出し・開きは破線の「く」の字で開き方を示す。
- **建具記号**
  - 円を横線で上下に分け、上に種別（AW/SD/SW/AD など）、下に番号。開口の中に置く。
- **境界線**
  - 縦の一点鎖線（または破線）に縦書きで「▽道路境界線」「△隣地境界線」と添える。
- **添景**
  - 車：細線または破線の透過した線画で、建物に重ねる。
  - 人物：立面図には描かない。
  - 植栽：ほぼ描かない。

### 多数派
- **CL（天井）のレベル**：△記号で立面図にも描く。
- **斜線制限**
  - 道路斜線・高度斜線を、細い一点鎖線または破線で描く。勾配は直角三角形に「1」と「1.25」「0.6」などを添える。
  - 検討式は図の上部に「対象部位：式 = 値 > 高さ …OK」の形でまとめる。
  - 描く面は、法規上効く面（1〜2面）だけ。
- **設備の注記**
  - 給排気口・配管・コンセント・宅配ボックスを外壁に描き、注記を付ける。書式は2通り。
    - 「排気口（室名/φ100/機械排気）」
    - 【排気口】／室名／φ100 の3段縦積み
  - 位置は CL からの下がり寸法で押さえる。
- **外壁の仕上**：材料名は書かず、目地・リブだけを細線で描く。注記するときも「左官-2」のような仕上表の記号止まり。
- **採光補正係数の検討寸法**：開口上部に縦書きで書き込む。

- **縮尺**：1:50（A2）／1:80（A3）／1:100（A3）。A3 に収まる縮尺を選んでいる。
- **レベル文字の位置**
  - 左だけ、右だけ、または2面の外側に左右対称。
  - 4面配置では、北・南が左、東・西が右といった分け方。

### Archicadでの出し方（推測を含む）
- 立面図設定 › モデル表示
  - 切断されていない要素の塗り：「陰影付き」か、材質の表面色。グレーのグラデーションはこれで出ていると推測する。
  - 輪郭線：均一ペン（細）。
- ガラス：材質の表面色を淡い青紫にする（参照図の色からの推測）。
- GL
  - 立面図の「地盤線」機能は使わず、線ツールの最太ペンで手描きしている可能性が高い。参照図に地盤ハッチがないため（推測）。
- 階高のストーリーレベル線
  - 立面設定の「ストーリーレベル」をオフにする。
  - 代わりにレベル寸法ツールか、ラベル＋線で「▽名称=GL+数値」を置く。
  - 基準の高さ：プロジェクト設定 › 参照レベルに「GL」を作り、レベル寸法の基準にする。
- 高さ寸法：寸法ツール（垂直）。
  - 端部記号：黒丸。文字：カンマ区切り。
  - CH は寸法文字の前に「CH=」を付ける（寸法テキストの接頭辞か、文字の置き換え）。
- 通り芯：立面設定で通り芯要素を表示し、記号は下側だけにする。
- 図名：レイアウト上の図面タイトル。種類は枠付き、縮尺は表示しない。
- ペンセット：モノクロ出力用。作業色はグラフィックオーバーライドで黒・グレーにまとめる。

### チェックリスト（立面図）
1. 図名は各面の下・枠囲み・縮尺なしになっているか。縮尺は図枠に書いたか。
2. 並べた面の GL・各レベルの高さが揃っているか。
3. GL は最太の実線1本で、建物外まで伸ばしたか（地盤ハッチなし）。
4. レベルは「▽名称=GL+数値」で、細い一点鎖線を図の外まで伸ばしたか。
5. 高さ寸法は2列以上か（分割と全高）。端部は黒丸か。
6. 通り芯記号は下側の丸囲みで、水平寸法を2段にしたか。
7. ガラスは淡い青紫の塗りと反射線か。FIX と建具記号（円を上下に分けたもの）を入れたか。
8. 色付きの作業線を残していないか。斜線制限は効く面にだけ式付きで描いたか。
9. 境界線を縦書きのラベル付きで描いたか。

## レベル・高さ表記（共通）


- **書式**
  - `▽名称=GL+数値` が基本。数値はカンマなし、単位なし。
  - GL そのものは `△GL` または `▽GL±0`。
- **記号の意味**
  - ▽（下向き）：上面のレベル。最高高さ・軒高・手摺天端・笠木天端・各FL・基礎天端。文字は線の上に置く。
  - △（上向き）：天井（各CL）と GL・平均GL・KBM。文字は線の下に置く。
  - 記号は白抜き。記号を文字の前に置くのが多数派。
- **名称と並び**（上から）
  - ▽最高高さ／▽軒高／△3CL／▽手摺天端／▽3FL／△2CL／▽2FL／△1CL／▽1FL／△GL
  - CL は FL とは別の行に書く。
- **基準**
  - すべて GL 基準の絶対値で書く。FL 基準（例：`=2FL+…`）は、手摺や笠木、浴室の水下などの局所だけ。
  - 法規の高さ（最高高さ・軒高）には、必要に応じて `,平均GL+…` か、2段目に `（平均地盤面+…）` を併記する。
  - 申請図には「◆備考 平均地盤＝設計GL±0」のような定義を書く。
- **線**
  - 細い一点鎖線（グレー）を、建物の外、図の幅いっぱいまで通す。
  - 横並びの複数面では、面をまたいで連続させる。
  - 長さの目安：レベル文字の外端から、反対側の境界線の外まで。
- **高さ寸法**
  - レベル文字のすぐ内側に置く。
  - 内側の列：分割寸法（基礎上→床懐→CH→天井懐→パラペット）。外側の列：全高（GL→最高高さ）。
  - 端部は黒丸、文字は90°回転、3桁カンマ区切り。
- **CH**：寸法列の中では `CH=2,xxx`（カンマ付き）、室内では縦書きで `CH2,xxx` か `浴室CH=…`。
- **GL の線**：立面図では最太の実線。断面図・矩計図では細い実線に地盤の帯を付ける。

## 11/16 の点検で足した決まり
- 建具記号（円を横線で上下に分け、上＝種別 AW/SD、下＝番号）を全ての開口に入れる。番号は平面図と同じ。
- レベル名は ▽最高高さ／▽軒高／▽2FL／▽1FL／△GL。「RFL」は書かない。
- 4面のレベル文字と高さ寸法の列：南・北は左、東・西は右。
- GL より下の基礎・床下は、画層「架空_地中（基礎）」を書き出し時に隠す。2D で隠さない。
