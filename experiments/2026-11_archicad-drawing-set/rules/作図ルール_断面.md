# 作図ルール：断面図（実務の断面図の描き方から。作法だけ）

## 前提（この家のモデル）
- 壁・床・屋根は複合構造（層のある部材）。断面の切断面には、Archicad が層ごとの塗りと区切り線を自動で出す。
- **切断面の上から塗りを重ねない**（層が見えなくなる）。RC がグレーのベタ、断熱材がハッチで出ているので、そのまま使う。
- 高さの基準：**GL＝敷地の上面（モデルの z=0）**。**1FL＝GL+100**（モデルの z=0.1）。高さは全部 GL 基準の絶対値で書く。値はモデル（ストーリー・スラブ・壁の高さ）から読む。

## 必ず描くもの
1. **レベル**
   - 書式：`▽名称=GL+数値`（カンマなし・単位なし）。GL は `△GL`。
   - ▽（上面：最高高さ・軒高・各FL）は文字を線の上、△（天井 CL と GL）は文字を線の下。
   - 並び（上から）：▽最高高さ／▽軒高／△2CL／▽2FL／△1CL／▽1FL／△GL。1FL と GL は別の線にする。
   - 線は細いグレーの一点鎖線。**図の幅いっぱい**（建物の中も横切る）に通す。文字は寸法列の外側に縦一列。
2. **高さ寸法**：レベル文字の内側に2列以上。
   - 内側の列：GL→1FL、CH、床懐（天井〜上の床）、CH、天井懐、パラペット。天井高は「CH=2,xxx」。
   - 外側の列：GL→最高高さの全高。
   - 端は黒丸、数字は3桁カンマ・90°回転。合計が全高と合うこと。
3. **天井高（室内）**：主な部屋の中に、床から天井までの縦の寸法線を引き、「CH2,xxx」と書く。
4. **室名**：室の中央に細い枠で囲む。LDK は全角で字間をあけた「ＬＤＫ」。CH は室名に付けない（寸法で示す）。
5. **通り芯**：丸記号を**上と下の両方**に。水平寸法は上1段（通り芯間）、下2段（通り芯間＋全長）。通り芯は <KIT>/grid.json の1組を使う。
6. **地盤**：GL は細い実線を建物の左右に長めに。建物の外側に、幅 1m ほどの土の斜線の帯を GL の下に入れる（建物の下には入れない）。
7. **基礎の下**：基礎の底の下に、捨てコン（厚 50）と砕石（厚 100）の帯を細線で描く。
8. **防水**：屋根の上面と、パラペットの立上りの内側に、青の細線を回す。笠木（パラペットの頭）を細線で描く。
9. **層構成の注記**（少なくとも屋根・外壁・2階床・1階床の4か所）
   - 見出し【部位】のあと1層1行。屋根・床は上→下、外壁は外→内。材料名と厚さはモデルの複合構造の名前・層から読む。
   - 引出線は細線で1回折る。矢印は付けない。外壁の注記は建物の外の余白、室内の部位は室の余白に置く。
10. **図名**：図の下中央に細い枠で「A-A 断面図」など。縮尺は書かない。

## 線と色
- 線はモノクロ。太さは「切断（モデルの輪郭）＞見えがかり＞層線＞寸法・レベル・通り芯」。
- 色を使うのは防水の青だけ。作業色を残さない。
- 見えがかり（切断面の向こう）の塗りは足さない。

## 重ならないように
- 文字・記号・寸法を、窓・階段・扉・ほかの文字に重ねない。置く前に、その範囲にモデルの線や文字が無いかを確かめる。
- 小さい寸法（300、400 など）が入らない時は、寸法線の外に引き出して書く。向きは列の中でそろえる。

## 点検（描いた後に数値で確かめる）
1. レベルの値がモデル（ストーリー・スラブの上端）と一致するか。立面図と同じ値か。
2. 高さ寸法の分割の合計＝全高か。水平寸法の合計＝全長か。
3. 切断面の上に塗りを重ねていないか（自分が作った塗りの範囲が切断面と重なっていないか）。
4. レベルの一点鎖線が図の幅いっぱいか。通り芯の記号が上下にあるか。
5. 室名・CH・注記が、窓・階段・扉と重なっていないか。

## 前回の失敗（11/16 の点検で見つかった。同じことをしない）
- 防水の青線を、笠木の上面や向こうに見える箱の上面に引いた。→ 青線は切断した屋根スラブの RC の上面（屋根の上端から 0.09〜0.10 下）と、パラペットの内側の立上りだけ。笠木の下で止める。
- 向こうに見える（切断されていない）パラペット・箱にグレーの塗りと太線を付けた。→ 見えがかりは細いグレー線だけ。
- 小さい寸法（300・400・100）がレベルの一点鎖線と重なった。→ 引き出して空いた所に書く。
- 層構成の注記を通り芯や扉枠の上に置いた。引出線が垂直で壁の線に見えた。→ 注記は室内の空いた所、引出線は斜めに1回折る。
- 基礎の下の帯が1本だけだった。→ 捨てコン 0.05 と砕石 0.1 の2本。
