# rules：作図ルール（描き方の決まり）

AI に渡した「描き方の決まり」です。どれも**ふつうの日本語の文章**で、プログラムではありません。実務の図面の描き方（作法）だけを整理したもので、形・間取り・数値は写していません。

| ファイル | 中身 | 使う指示 |
| --- | --- | --- |
| [作図ルール_平面.md](作図ルール_平面.md) | 平面図：通り芯・外周寸法（2段）・室名（名前・面積・帖）・建具記号・床の淡い塗り・図名、Archicad での出し方、チェックリスト | `10_sheet_P1`・`11_sheet_P2`・`23_`〜`25_` |
| [作図ルール_断面.md](作図ルール_断面.md) | 断面図：必ず描くもの1〜10（レベル・寸法・層構成の注記・地盤・防水の線など）、線と色、重ならないように、点検、前回の失敗 | `12_sheet_SA`・`13_sheet_SB`・`20_`〜`22_` |
| [作図ルール_立面.md](作図ルール_立面.md) | 立面図：塗りの作り方、注記の置き方、Archicad で確かめた出し方、レベル・高さ表記（共通）、11/16 の点検で足した決まり | `03_`・`14_`〜`17_` |

- 指示は、描く図の種類のルールを1つだけ読ませます（全部を一度に渡すより、よく守られるため）。
- `scripts/prepare_workdir.py` が、このフォルダのルールを作業フォルダ（`work/`）にコピーします。ルールを書き換えたら、段 0 の準備をもう一度流すか、`work/` の同じ名前のファイルにもコピーしてください。
- 自分の事務所の描き方に書き換えれば、そのまま自分の事務所のスキルになります（README の「自分の事務所で使うには」）。
