# AI_GUIDE — 家具レイアウト担当エージェント向け手順

あなた（Claude Code / Codex など、シェルを実行できる AI エージェント）は、ユーザーの自由文の依頼から
**Archicad で今開いている部屋を読み、配置を自分で設計し、ルールで確認し、Archicad に反映**します。
Unreal は人間が起動した見張り（`ue/ue_follow.py`）が Archicad の家具を読んで自動で追従します（Unreal は操作しない。`ue/` のファイルも実行・変更しない）。

作業フォルダは、この `AI_GUIDE.md` があるフォルダ（以下 `<KIT>`）。コマンドはすべてこのフォルダで実行します。

## 0. 初回の準備と接続確認（人に頼まれた時・初めての時だけ）

1. Archicad に Tapir アドオンが入って動いていること（入っていなければ、人にセットアップ資料 https://claude.ai/artifact/UwQrsxsWJztdwNVAd93t8T#ja の手順を案内する）。
2. `uv` が使えること（`uv --version`）。無ければ入れる。必要なライブラリ（numpy / matplotlib / shapely）は初回の `uv run` で自動で入る。
3. `config.json` を、Archicad で開いているモデルに合わせる（人と相談して決める）。
   - `room_zone_name`：対象の部屋のゾーン名（例「LDK」）。部屋はゾーンで描いてある前提
   - `kinds`：ライブラリ部品の名前 → 家具の種類（日本語・英語の代表的な名前は入っている）
   - `kind_by_guid`：代用品の指定（例：ランプの代わりにスツールの部品を置いている）
   - `keep_out`：家具を置かない四角（`reach: true` を付けると「人が出入りする場所」として通路の行き先にもなる）
   - `fixtures`：モデル化していない設備（キッチン台など）
   - 入っている値は、実験で使った架空の家の物
4. 接続確認：`uv run read_room.py` を1回流し、家具の一覧が出ること、種類が `other`（id が `obj…`）になっている家具が無いことを確かめて、人に一覧を見せる。
5. Unreal Engine 側は人の作業（`ue/README.md`）。あなたは Unreal Engine を操作しない。

`recorded/` は実験で AI が書いた配置、`examples/` は開発中の動作確認の記録。どちらも答えなので読まない・流用しない。

## ループ（毎回この順で。用意済みの配置案は使わない）

1. **部屋を読む** — `uv run read_room.py`
   - `room.json` ができる。印字された家具一覧（id・種類・寸法・中心・向き）と、
     `room.json` の `room.polygon`・`openings`（窓の窓台高さ `sill_m`、ドアの開閉スペース `clear_zone`）・
     `entries`（入口）・`keep_out`（階段など）・`fixtures`（未モデルのキッチン等）を読む。
   - 依頼のたびに読み直す（前の依頼で家具が動いているかもしれない）。
2. **設計する** — 依頼文を 1 文の「ねらい」に言い換え、`layouts/<短い名前>.json` を書く（形式は下）。
   - **はっきり違う配置にする**。主要なグループ（ソファ周り・ダイニング・TV）を 3〜5 m 動かすのが普通。
     数十 cm ずらすだけの案は不可（チェッカーの `moved ... max` で確認できる）。
   - 動かす家具だけ書けばよい。書かない家具は今の位置のまま。
   - 寸法の目安: 壁付けは「壁から 奥行き/2」、ダイニングチェアは「テーブル端＋椅子奥行き/2」で寄せる、
     ラグの中心＝座卓の中心、TV は TV 台と同じ中心・同じ向き、ソファ→TV は 2.0〜3.6 m。
3. **確認する** — `uv run check_layout.py layouts/<名前>.json`
   - `PASS` か、番号付きの違反一覧（`[ルール] 内容 -> 直し方`）が出る。上面図 PNG も同じ名前で出る。
   - 違反を直して再実行。**最大 3 回**。3 回で PASS しなければ反映せず、何が両立しないかを 1〜2 行でユーザーに返す。
   - 通路で詰まったら `--paths` を付けると、通れる床（濃い緑 0.8 m／薄い緑 0.6 m）が PNG に描かれる。
4. **反映する** — `uv run apply_layout.py layouts/<名前>.json`
   - PASS した内容でないと拒否される。Tapir の 1 回の呼び出しで全点を動かし、1 行の JSON を返す
     （`pieces` 点数・`tapir_modify_s` 反映時間・`since_read_room_s` 読み取りからの経過・`max_error_mm`・`undo` ファイル）。
5. **返信する（1 行）** — 何をどう変えたか＋時間。例:
   `ソファを南の窓下に移して向かい合わせのカフェ席に、ダイニングは東へ（17点・Archicad反映0.6秒・読み取りから2分10秒）`

元に戻すとき: `uv run apply_layout.py undo/<時刻>.json`（apply が自動で保存した直前の位置）。

## レイアウト JSON

```json
{
  "request": "ユーザーの依頼文そのまま",
  "title": "短い題（図の見出しになる）",
  "concept": "ねらいを1〜2文",
  "pieces": {
    "<家具id>": [x, y, facing],
    "sofa": [10.3, -1.14, 90]
  },
  "exceptions": [
    {"rule": "sofa_faces_tv", "piece": "sofa", "reason": "カフェ席はテレビでなく向かいの席を向く"}
  ]
}
```

- 座標は m（Archicad の平面座標）。`[x, y]` は家具の**中心**。
- `facing` は度。0 = +x（東）、90 = +y（北）、180 = 西、-90 = 南。**人が座る・使う側**の向き
  （ソファなら座ったときに顔が向く方向、TV なら画面の向き、棚なら手前側）。
- 家具 id は `read_room.py` が印字したもの（`sofa`, `lounge1`, `dchair3` …）。知らない id は違反になる。
- `exceptions` は「意図的にルールを外す」宣言。下の **緩いルール** だけに使え、理由が必須。図と結果に「例外」と表示される。

## ルール（check_layout.py）

| 種類 | ルール id | 内容 |
|---|---|---|
| 厳守 | inside_room | 部屋の輪郭（ゾーン）の内側 |
| 厳守 | keep_out | 階段・`keep_out`・キッチン台とその前 0.9 m・ドアの前 0.8 m に置かない（ラグは通路帯なら可） |
| 厳守 | overlap | 家具どうしが重ならない（椅子とテーブル、TV と TV 台は除く） |
| 厳守 | tv_on_unit | TV は TV 台の上、同じ向き |
| 厳守 | tv_on_solid_wall | TV 台の背は壁に付け、背後に「TV の上端＋0.3 m より低い」窓・ドアが無いこと（高窓の下は可） |
| 厳守 | dining_chairs | 椅子はテーブル向き、片側の椅子は中心に対称、後ろに 0.6 m 引ける |
| 厳守 | dining_near_kitchen | ダイニングテーブルはキッチン台から 2.5 m 以内 |
| 厳守 | main_path | 入口からキッチン前・各ドア・他の入口・`reach` 指定の場所（階段の降り口など）へ幅 0.8 m の通路 |
| 厳守 | secondary_path | 座る家具・椅子（引いた位置）・棚へ幅 0.6 m の通路 |
| 緩い | sofa_faces_tv / sofa_tv_distance | ソファは TV へ ±15°、2.0〜3.6 m |
| 緩い | rug_centred / rug_under_seats / rug_not_under_tv_unit | ラグは座卓中心、座卓 2 m 以内のソファ・ラウンジの前脚が乗る、TV 台の下に入れない |
| 緩い | lounge_to_centre | 座卓近くのラウンジは会話の中心へ ±25° |
| 緩い | wall_aligned | 壁に平行（0/90/180/270°）。斜めは例外として理由を書く |
| 緩い | plant_place / side_table_by_seat / lamp_by_seat / shelf_on_wall | 植物は隅か家具の横、サイドテーブル・照明は席の横、棚は壁付け |
| 緩い | chair_at_table | ダイニングチェアはテーブルに寄せる |

チェッカーは参考値も出す: 動かした点数と距離（3 m 以上動いたもの）、空き床の最大円の直径（「真ん中を空けて」の評価に使う）、ソファ–TV 距離、ダイニング–キッチン距離。

## してはいけないこと

- `room.json` を手で書き換えない。config.json は人間の設定（変えるなら理由を言う）。
- `apply_layout.py` 以外で Archicad を書き換えない（作成・削除・保存・RebuildView をしない）。1 依頼につき反映は 1 回。
- Unreal を操作しない。examples/・recorded/ の配置を流用しない（動作確認の記録。部屋の今の状態から毎回設計する）。
