# 11 Rhino を使わずに、採点のしかただけ確かめる

この指示は公開キット用に新しく書いたものです。**キット**＝このファイルがある `prompts` フォルダの1つ上のフォルダです。コマンドはキットのフォルダで実行します。

## 決まり
返事はユーザーと同じ言語で、建築の言葉で短く。コマンド・パス・プログラム用語は見せない。コマンドは全部あなたが実行する。結果を作らない。公開済みの結果（`results/`・`run2_recorded/results/`）は上書きしない。

## 手順
1. **Python と画像処理の道具**：`uv` があれば下のコマンドのままでよい。無ければ Pillow と numpy を、ユーザーの許可を得て入れる。
2. **採点を動かす**（数分かかる）：同梱の影絵（実験で Rhino から撮った物）で、録画した回の採点をやり直す。
   `uv run -q --with pillow --with numpy python scripts/metrics_live.py results/silhouettes --out work/results_check`
3. **比べる**：`work/results_check/metrics_live.json` と `run2_recorded/results/metrics_live.json` が同じかを確かめる（実験の公開前に同じになることを確かめてある）。
4. **ユーザーに表で伝えて止まる**：録画した回の重なり率（真上 A 68%／B 100%、正面 76%／99%、右側面 80%／97%、裏 76%／96%）と、今出した値が同じか。違えば、違った所を正直に。
   採点のしかたをひとことで：「正解と AI の模型を同じ向きから影絵で撮り、重なった面積を、どちらかが占める面積で割っています。位置のずれは ±3m の範囲で一番重なる所に合わせてから測っています」。
   比較の画像の場所（「このフォルダの work の中の results_check」）。
