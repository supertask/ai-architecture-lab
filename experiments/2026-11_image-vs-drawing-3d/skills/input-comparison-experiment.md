# 入力の違いで 3D 模型の精度を比べる（外観だけ vs 外観＋図面）

## 1. 作らせる側を公平に分ける
- A（外観だけ）と B（外観＋図面）は、**別々の新しい会話**で頼む。過去の会話・メモリ・スキルを持たない状態にする。
- 渡すファイルを明記し、**それ以外は開かない・一覧しない**と書く。答えになるファイル（正解の模型スクリプト、図面を描いたスクリプト、作業記録）は名指しで禁止する。読まれると検証が無効になる。
  - いちばん確実なのは、入力だけを入れた別フォルダで AI を起動すること（`scripts/prepare_run.py`）。
- 指示文は A と B で「図面を渡すか」以外を同じにする。出力の形を決めておく：
  - `model.py`：RhinoCommon の Python。全オブジェクト削除 → Brep を決まったレイヤー（`M_Concrete / M_Glass / M_Wood / M_Water / M_Paving / M_Asphalt`）に追加、mm、Z 上、道路は −Y、最後に `result = 'ok'`。
  - `params.json`：仮定した寸法・根拠・確信度。`notes.md`：読めた所／推測した所／見えない面。
  - 構文確認（`python -m py_compile model.py`）までさせる。
- B には座標系を図面のグリッドに合わせさせる（px→mm の縮尺も渡す）。A は原点が決まらないので、採点側で位置をそろえる。
- 「スクリプトを書くだけ」（Rhino 接続不要）と「Rhino に部分ごとに送って組む」（Rhino 接続が要る・録画向き）の2通りがある。後者は Rhino を触る AI を1つだけにする（同じ文書を消し合う）。

## 2. 同じ条件で撮る（`scripts/run_compare.py`）
- 模型を実行 → 地面・道路を共通のものに差し替え → 共通の素材 → 外観と同じカメラ・裏左右・右前・斜め上 → 地面を隠して平行投影の Shaded で `sil_top / front / right / back`。
- A は `ALIGN=True`（壁の外接箱の左端・最前を正解にそろえる。**高さは地面 = 0 のまま**。z まで外接箱で合わせると基礎や水盤の底で全体が浮く）。
- **数値を出す前に、模型が立体になっているかを画像で確かめる**。押し出しのソリッドが内向きだとブール演算で壁が消え、重なり率が「形の差」ではなく「描画の失敗」を測ってしまう。直すのは実行上の不具合だけ（例：`if brep.SolidOrientation == G.BrepSolidOrientation.Inward: brep.Flip()`）。寸法は触らず、直したことを記録に残す。

## 3. ずれを数字と図で出す（`scripts/metrics.py`）
- 背景色（画像の縁の中央値）との差で影絵を取り、正解との重なり率（IoU ＝ 重なった面積 ÷ どちらかが占める面積）・足りない率・余分な率を視点ごとに出す。
- 原点の決め方の差を消すため、比べる前に ±60px（約 ±3m）の平行移動で一番重なる位置へ合わせる。A・B に同じ処理をかけ、そのことを書く。
- 重ね図：灰＝一致、赤＝足りない、青＝余分。片側が青・反対側が赤の均一な帯は位置ずれのサイン。

## 4. まとめるときに必ず書くこと
- 正解も図面どおりの模型なので、図面を渡した側が有利な比べ方であること。
- 試行回数（1回ずつなど）と、AI の答えは毎回変わること。
- 図面を渡した側の外れは、たいてい図面に書いていない所か、図面の中の食い違いから来る。見つけたら「図面に1つ書き足せば防げる点」として記録する。
- 外観だけの側は「目の高さ」など1つの仮定から全体の縮尺を逆算する。その仮定で建物の大きさが丸ごと変わる（params の確信度で示せる）。

## 撮影の落とし穴（Rhino の ViewCapture）
- **正解も比べる模型も、同じ Rhino の窓の大きさで撮る**。`ZoomBoundingBox` はビューの縦横比で合わせるので、窓の大きさが変わると縮尺が変わり、重なりが 30% 台に落ちる（形は合っているのに半分の大きさに写る）。値が急に崩れたら sil_*.png を並べて大きさを見る。
- 真上の平行投影は `CameraUp = (0,1,0)`、それ以外は `(0,0,1)`。指定しないと建物が斜めに写る。
- 平行投影で `ZoomBoundingBox` だけだと左右が切れることがある。続けて `vp.Magnify(0.62, False)` で引く。
- 正面の平行投影には、側面向きのガラスは写らない（欠けではない）。
- Rendered 表示の撮影は露出が強め・影なし。見せ用には壁テクスチャを少し暗くした複製を使う（`scripts/make_tex.py`）。
